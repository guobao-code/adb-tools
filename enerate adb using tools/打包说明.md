# ADB工具打包说明

## 快速开始

### 方法1: 使用批处理脚本(推荐)

#### 正式版本打包(无控制台)
```bash
双击运行: build_exe.bat
```

#### 调试版本打包(带控制台)
```bash
双击运行: build_exe_debug.bat
```

### 方法2: 手动命令行打包

#### 基础打包
```bash
cd "d:\git-warehouse\obtain-sports-videos\enerate adb using tools"
pyinstaller adb_gui.py
```

#### 单文件打包(推荐)
```bash
pyinstaller --onefile --windowed --name "ADB工具" adb_gui.py
```

#### 调试版本(带控制台)
```bash
pyinstaller --onefile --name "ADB工具_调试版" --console adb_gui.py
```

## PyInstaller 参数说明

| 参数 | 说明 |
|------|------|
| `--onefile` | 打包成单个可执行文件 |
| `--windowed` | 不显示控制台窗口(Windows下) |
| `--console` | 显示控制台窗口(用于调试) |
| `--name` | 指定输出的可执行文件名 |
| `--icon` | 指定图标文件(如 `app.ico`) |
| `--add-data` | 添加非代码文件(格式: `源路径;目标路径`) |
| `--noconfirm` | 覆盖输出目录时不提示确认 |

## 使用说明

### 部署步骤

1. **复制文件**
   - 将 `dist\ADB工具.exe` 复制到目标位置
   - 建议将 `adb.exe` 与 `ADB工具.exe` 放在同一目录

2. **环境配置**
   - 确保系统已安装 Android SDK Platform-Tools
   - 将 adb.exe 所在目录添加到系统 PATH 环境变量

3. **运行程序**
   - 双击 `ADB工具.exe` 即可运行
   - 首次运行可能需要防火墙/杀毒软件授权

### 分发建议

1. **创建安装包**
   - 使用 NSIS 或 Inno Setup 创建安装程序
   - 自动配置环境变量和依赖

2. **便携版**
   - 将 `ADB工具.exe` 和 `adb.exe` 放在同一目录
   - 用户可直接运行，无需配置环境

3. **包含说明**
   - 添加使用说明文件
   - 提供常见问题解答

## 常见问题

### 打包失败

**问题1: PyInstaller 找不到模块**
```
解决: pip install 缺少的模块
```

**问题2: 编码错误**
```
解决: 确保源代码使用 UTF-8 编码保存
```

**问题3: 路径包含中文或空格**
```
解决: 使用英文路径或用引号包裹路径
```

### 运行问题

**问题1: 提示"未检测到ADB"**
```
解决:
1. 确认 adb.exe 是否在系统 PATH 中
2. 或将 adb.exe 与程序放在同一目录
3. 重启程序
```

**问题2: 设备未显示**
```
解决:
1. 检查USB调试是否开启
2. 尝试更换USB端口或数据线
3. 点击"重启ADB服务"按钮
```

**问题3: 杀毒软件误杀**
```
解决:
1. 将程序添加到白名单
2. 或使用调试版本查看具体错误
```

## 优化建议

### 减小文件体积

1. **使用虚拟环境**
```bash
python -m venv venv
venv\Scripts\activate
pip install pyinstaller
# 打包
```

2. **排除不必要的模块**
创建 `adb_gui.spec` 文件，添加:
```python
excludes=['tkinter', 'unittest', 'email']
```

3. **使用UPX压缩**
```bash
pyinstaller --onefile --upx-dir="C:\UPX" adb_gui.py
```

### 添加图标

1. 准备 `.ico` 格式图标文件
2. 使用参数: `--icon=app.ico`
