# 给单个设备安装APK使用说明

## 功能说明

已为ADB工具添加了单个设备安装APK的功能，支持两种方式：

### 方式一：通过设备卡片直接安装（推荐）

1. **在设备卡片上找到"安装APK"按钮**
   - 每个设备卡片上现在有5个按钮
   - 第一行：断开、控制、安装APK
   - 第二行：文件、信息

2. **点击"安装APK"按钮**
   - 直接为该设备选择APK文件进行安装
   - 无需额外选择设备，快捷方便

### 方式二：通过顶部工具栏安装

1. **点击顶部工具栏的"安装APK"按钮**
   - 位置：设备管理区域 → 操作按钮栏 → "安装APK"

2. **选择目标设备**
   - 如果只有一个已授权设备：直接安装到该设备
   - 如果有多个已授权设备：弹出设备选择对话框，选择要安装的设备

3. **选择APK文件**
   - 在文件选择对话框中选择要安装的APK文件
   - 支持.apk格式文件

4. **查看安装进度**
   - 安装过程会显示在日志输出区域
   - 安装成功后会显示绿色成功信息

## 使用场景

### 场景1：单个设备安装APK
- 直接在设备卡片上点击"安装APK"
- 选择APK文件
- 等待安装完成

### 场景2：多个设备，给特定设备安装APK
- 方式一：在目标设备的卡片上点击"安装APK"
- 方式二：点击顶部"安装APK"，在弹出的对话框中选择目标设备

### 场景3：多个设备，给所有设备安装相同APK
- 点击顶部"安装APK"
- 依次为每个设备选择并安装APK
- 或使用自定义ADB命令批量安装

## 安装命令说明

- 命令格式：`adb -s <设备ID> install -r "<APK文件路径>"`
- `-r` 参数表示覆盖安装（如果已存在）
- 安装成功会返回 `Success` 状态码
- 安装失败会在日志区域显示错误信息

## 常见问题

### Q1: 点击"安装APK"没有反应
A: 检查是否有已授权的设备连接

### Q2: 安装失败，提示"Failure [INSTALL_FAILED_UPDATE_INCOMPATIBLE]"
A: 表示新APK与已安装的应用包名冲突但签名不同，需要先卸载旧版本

### Q3: 安装失败，提示"Failure [INSTALL_FAILED_INSUFFICIENT_STORAGE]"
A: 设备存储空间不足，需要清理空间

### Q4: 安装失败，提示"Failure [INSTALL_FAILED_PERMISSION_MODEL_DOWNGRADE]"
A: 新APK的权限要求低于旧版本，无法降级安装

### Q5: 安装速度很慢
A: 检查网络连接质量，无线ADB连接速度可能较慢

## 进阶用法

### 使用自定义ADB命令安装

在"自定义ADB命令"区域输入：
```
install -r "C:\path\to\app.apk"
```
在"目标设备"下拉框中选择特定设备，然后点击"执行命令"。

### 批量安装多个APK

可以编写批处理脚本：
```batch
@echo off
set device=10.0.0.30:5555
adb -s %device% install -r "app1.apk"
adb -s %device% install -r "app2.apk"
adb -s %device% install -r "app3.apk"
```

## 快捷键

- **设备卡片按钮**：点击直接执行对应操作
- **刷新设备列表**：点击"刷新设备列表"或按F5（如果添加了快捷键）
- **自定义命令**：输入命令后按Enter执行
